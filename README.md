# 👗 Bellaver

Projeto final em Java desenvolvido como atividade de programação back-end, simulando etapas básicas de uma experiência de compra em uma loja de roupas.

## Sobre o projeto

O programa funciona pelo terminal e reúne diferentes conceitos estudados em Java em um único fluxo: cadastro/login, escolha de produtos, seleção de características, cálculo do valor da compra, desconto e forma de pagamento.

## Funcionalidades

- Cadastro básico de usuário
- Simulação de login
- Envio de mensagem ao vendedor
- Catálogo de roupas e calçados
- Escolha de cor e tamanho
- Carrinho com múltiplos produtos
- Cálculo do valor total
- Aplicação de desconto conforme a regra definida no projeto
- Escolha da forma de pagamento

## Tecnologias e conceitos

- Java
- Entrada de dados com `Scanner`
- Estruturas condicionais
- `switch`
- Laços de repetição
- Variáveis e operações aritméticas

## Arquivos principais

```text
Programacao_Back_End.java  # Código-fonte do programa
Bellaver.docx              # Documentação do projeto
```

## Como executar

1. Tenha o JDK instalado.
2. Compile o arquivo Java.
3. Execute a classe `Programacao_Back_End` pelo terminal ou por uma IDE compatível.

## Observação

Este é um projeto educacional. Os dados de cadastro e pagamento são apenas simulados durante a execução e não são processados por um sistema real.
